# Acceptable Use Policy

Official publication and release infrastructure is intended for lawful,
authorized education and collaboration.

Do not use official channels to expose credentials or personal data, bypass
provider billing or access controls, distribute malware, misrepresent an
unofficial release as official, or interfere with project infrastructure.
Users remain responsible for the work, accounts, data, and systems they connect
to any workflow described by these publications.

Report security-sensitive abuse through the private path in `SECURITY.md`.
