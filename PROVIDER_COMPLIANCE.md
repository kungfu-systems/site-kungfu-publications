# Provider Compliance Policy

Publications in this repository describe integrations and workflows that should
use provider-supported APIs, SDKs, CLIs, telemetry, exports, and explicit
user-owned credentials.

Official material must not encourage scraping private application state,
reading hidden credential stores, pooling provider accounts, bypassing billing
or quotas, or presenting estimates as exact usage facts. Version-sensitive
provider behavior must be identified as such and linked to authoritative
documentation where practical.
