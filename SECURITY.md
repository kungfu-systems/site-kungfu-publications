# Security Policy

Report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/kungfu-systems/site-kungfu-publications/security/advisories/new).

Do not place credentials, private logs, exploit details, or personal data in a
public issue or pull request. Include the affected file or release, reproduction
steps, impact, and whether the problem affects source, generated Markdown, PDF
artifacts, or release automation.
